## Global Context

`InterfaceLayer` is exposed to QML with:

```cpp
engine.rootContext()->setContextProperty("InterfaceLayer", &iface);
```

QML calls backend actions through:

```qml
InterfaceLayer.dispatch("command.name", { key: value })
```

## Connection Status

`connectedTime` and `connectedTimeStr` are exposed on `InterfaceLayer` for the home page connection status.

## Mouse Input

`touchpad.qml` sends `mouse.move`, `mouse.button` and `mouse.releaseAll` routes.
`passthroughMouseListening` mirrors the app-foreground mouse capture switch.
All mouse reports pass through `MouseInputManager`, `MouseProtocol` and the
shared `InputQueue` before reaching BLE, UART or HUDP.
